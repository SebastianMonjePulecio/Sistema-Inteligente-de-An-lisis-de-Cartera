📊 Sistema Inteligente de Análisis de Cartera
🎯 Descripción

Proyecto de análisis de cartera enfocado en la identificación de riesgo crediticio y optimización de la gestión de cobranza.

Se desarrolló un sistema utilizando Python y Power BI para:

Analizar comportamiento de clientes
Identificar niveles de mora
Priorizar clientes según riesgo
Generar indicadores financieros clave
🛠️ Tecnologías utilizadas
Python (Pandas, NumPy)
Google Colab
Power BI
Excel
📈 Funcionalidades
Generación y análisis de datos de cartera
Segmentación por niveles de mora
Clasificación de riesgo crediticio
Cálculo de KPIs financieros
Dashboard interactivo en Power BI
Priorización de clientes
📌 Hallazgos clave
Se identificó concentración de riesgo en clientes con mora alta
Un grupo reducido representa mayor impacto financiero
La mora está distribuida en diferentes niveles
Se observan patrones entre ingresos y comportamiento de pago
🚀 Valor de negocio

Este proyecto permite:

Mejorar la toma de decisiones
Optimizar la gestión de cobranza
Reducir el riesgo crediticio
Priorizar clientes estratégicamente
